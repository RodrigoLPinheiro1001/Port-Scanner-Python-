# TC VISION
"TC VISION" is an on-going project focused mainly on, via IP adress, detecting and scanning all TCP and UDP open ports. The idea of this project came by as an attempt to do a project that, at the same time, can be usefull for future tasks and teach me alot of things while building this project.

# What is it capable of??
The project is able to search an entire network and check all the open TCP ports (in the future the scan will work with the UDP protocol too). In addition to that you can even test your connection to the internet. 
Thats all it can do --> for now <--

# What tools does it use??
TC Vision is a project mainly focused on Python. The choice was made by its efficiency at reading/writing high-quantity of data and by its amazing quantity of libraries of all subjects.

## Libraries
- socket
- ipadress
- rich
- sys
- pyfiglet
- datetime
